# dotfiles

My Hyprland desktop setup on Fedora — a custom AGS (Astal) status bar, Hyprland window management tweaks, and supporting scripts.

## What's included

- **Hyprland** (`Hyprland/hyprland.lua`) — window rules, keybinds (vim-style navigation, window swapping, scratchpads), workspace/border theming, custom transparency toggle
- **AGS bar** (`AGS/`) — custom status bar built with Astal: colored workspace indicators, live CPU/RAM/wifi/bluetooth/volume/brightness with hover tooltips and interactive sliders
- **SwayOSD** (`swayosd/`) — custom-styled on-screen volume/brightness popups
- **Kitty** (`kitty/`) — terminal config and theme
- **Scripts** (`scripts/`) — scratchpad toggles for terminal, Dolphin, and Gnote

## Notable features

- Vim-style window focus (`Alt+h/j/k/l`)
- Per-workspace custom colors
- Dropdown scratchpad terminal, file manager, and notes app
- Live hover sliders for volume/brightness directly in the bar
- Teal/blue gradient borders on floating windows, purple/teal on tiled
